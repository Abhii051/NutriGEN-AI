# NUTRIGEN-AI

NUTRIGEN-AI is a personalized nutrition and diet optimization system.

## Architecture

- Streamlit: Frontend/UI
- FastAPI: Backend/API
- Python: Core nutrition and optimization logic
- Pandas: Food and nutrition data processing
- PuLP: Diet optimization
- Scikit-learn: Machine learning components
